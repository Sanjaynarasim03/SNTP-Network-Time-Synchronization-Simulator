# SNTP Network Time Synchronization Simulator

> **Course:** Network Protocols and Analysis (NPA)  
> **Standard:** RFC 4330 / RFC 5905  
> **Stack:** Python 3 (standard library: `socket`, `struct`, `threading`), Flask, Chart.js  
> **Operation:** 100% Offline Localhost Simulation  

A comprehensive, interactive mini-project simulator for studying the **Simple Network Time Protocol (SNTP)**. Features real 48-byte UDP datagram packing, bidirectional 1900/1970 epoch conversion, virtual clock drift modeling, network impairment simulation, an animated $T_1 - T_4$ message timeline, a raw 48-byte packet inspector, and pre-configured experiment scenarios.

---

## Key Features

1. **RFC 4330 SNTP UDP Server (`udp://127.0.0.1:1123`):**
   - Implements the exact 48-byte binary format with `struct.pack/unpack`.
   - Authoritative Stratum 1 local clock with sub-microsecond precision.
   - Accurately stamps $T_2$ (receive) and $T_3$ (transmit) timestamps.

2. **SNTP Client & Software Virtual Clock:**
   - Measures $T_1$ and $T_4$, computes Clock Offset ($\theta$) and Round-Trip Delay ($\delta$).
   - Safely adjusts a **Virtual Clock** with frequency drift (ppm) without touching your OS system clock.

3. **Network Impairment Simulator:**
   - Configurable forward & return latency, random jitter ($\pm\text{ms}$), packet loss (%), and timeouts.
   - Demonstrates the fundamental **Asymmetric Delay Theorem**: Offset Error = $-\Delta / 2$.

4. **Multi-Client Architecture:**
   - **Client A (Campus LAN):** Low delay, low jitter, 0% loss.
   - **Client B (WAN / 4G):** Medium delay, higher jitter, 5% loss.
   - **Client C (Satellite Link):** Asymmetric link (10ms forward vs 90ms return).

5. **Presentation-Ready Dark Dashboard:**
   - **Live Simulation:** Animated $T_1-T_4$ packet exchange with substituted formula calculation, live Chart.js graphs, and color-coded packet tables.
   - **Packet Inspector:** Interactive 48-byte visual field diagram and hex stream viewer.
   - **Experiments Mode:** 5 one-click laboratory scenarios with before/after charts and academic explanations.
   - **Logs & Export:** Export sync logs to CSV and charts to PNG.

## Quick Start (Run with One Command)

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Launch the Application
```bash
python3 run.py
```
Open your browser and navigate to:
```
http://127.0.0.1:5000
```

## Wireshark Capture on Localhost

To inspect the real binary UDP packets generated by the simulator:
1. Open Wireshark and select interface **Loopback (`lo0` / `lo`)**.
2. Set display filter to:
   ```text
   udp.port == 1123
   ```
3. Click **"Sync Once"** in the web dashboard.
4. Verify that the 48-byte payload matches the **Packet Inspector** tab in the dashboard!
